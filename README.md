# git-roots-manager

Плагин PhpStorm: переключение отслеживания git-корней монорепозитория
из статус-бара. Клик по чекбоксу применяется мгновенно, без кнопки Apply.

## Сборка

```bash
cp local.properties.example local.properties  # указать путь к PhpStorm
./gradlew buildPlugin
```

Путь к локально установленному PhpStorm (целевая сборка PS-262) берётся из
`local.properties` (`idePath=...`, не коммитится) или переменной
`PHPSTORM_IDE_PATH`; без них сборка падает с подсказкой. Локальный IDE нужен,
потому что `download.jetbrains.com` для PhpStorm недоступен из региона.

Результат: `build/distributions/git-roots-manager-0.1.0.zip`.

Требования: JDK 21 (toolchain).

## Установка

Settings → Plugins → ⚙ → **Install Plugin from Disk** → выбрать zip →
перезапустить IDE.

## Использование

- иконка в статус-баре (справа внизу) → диалог со списком git-корней проекта,
  включая вложенные;
- строка `<Project>` — маппинг всего проекта: сняли чекбокс — отслеживание
  отключается целиком, поставили — возвращается именно как `<Project>`;
- корень проекта и вложенные репозитории управляются так же: сняли чекбокс —
  мгновенно исчезают из отслеживания (панель Commit и т.д.), поставили —
  мгновенно возвращаются;
- «Включить все» / «Выключить все» затрагивают и корневой репозиторий
  (полное включение/отключение VCS одним кликом);
- корень, выключенный через плагин или прямо в настройках IDE, остаётся в
  списке (снятым чекбоксом) и включается обратно из плагина; после
  пере-детекции платформы и перезапуска IDE выключенные не возвращаются.

## Где хранится состояние

- включённые корни — `.idea/vcs.xml` (штатные directory mappings платформы);
- выключенные — `workspace.xml` (компонент `GitRootsManagerState`); пустой
  `directory` в записи означает выключенный маппинг `<Project>` — при
  включении восстанавливается именно он;
- выключенные корни (включая корень проекта) заносятся в игнор-лист
  `VcsConfiguration` (workspace), чтобы детектор корней не предлагал их снова.
